# Async resources

Asynchronous resource classes. Reach them through an
[`AsyncAtonixClient`][atonix.AsyncAtonixClient]. They mirror the [sync resources](resources.md):
methods returning one object or a list are coroutines, and paginated methods return async
iterators.
