# Support

`atonix` is an independent, volunteer-maintained open-source project. It is **not** an official
Prometheus Group product, and it is **not** supported by Prometheus Group.

## Getting help

- **Bugs and feature requests:** open a [GitHub issue](https://github.com/stimpert-labs/atonix/issues).
- **Questions and usage help:** open an issue with the `question` label.
- **Security vulnerabilities:** report privately as described in [SECURITY.md](SECURITY.md).
- **Problems with the Prometheus APM service itself** (outages, accounts, API keys, permissions,
  data issues): contact Prometheus Group or your APM administrator.

When filing an issue, never include credentials, private keys, tenant URLs, customer or plant names,
or real tag/asset identifiers.

## What to expect

Support is provided on a **best-effort basis only**. There is no service-level agreement, and no
guarantee of a response, fix, or release on any timeline. The software is provided "as is", without
warranty of any kind — see [NOTICE](NOTICE) and the README's Disclaimer section.

If you need guaranteed support for production use, plan to maintain your own fork or engage a
commercial provider.
